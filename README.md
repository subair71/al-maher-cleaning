# Al Maher Cleaning Services

Arabic-first, responsive cleaning services website with English translation and WhatsApp enquiries.

Static website files are in the repository root. Open index.html to preview.

Current published site: https://al-maher-cleaning.subair-info7.chatgpt.site

To host on GitHub Pages, select Settings → Pages → Deploy from a branch → main → / (root).

The original company logo is preserved. Photography sources are documented in PHOTO_SOURCES.md.
